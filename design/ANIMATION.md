# 욥기 설명 애니메이션

욥기를 처음 접하는 독자를 위한 6편 / 37컷 / 기본 재생 시간 400초(6분 40초).
기기 음성이 느리면 현재 컷의 자막을 유지하여 음성이 잘리지 않게 합니다.

## 구성
1. 욥 소개, 하늘 법정에서 하나님과 사탄의 대화 (1:1–12)
2. 상실, 두 번째 하늘의 대화, 몸의 고통, 아내, 탄식 (1:13–3:26)
3. 일곱 날의 침묵, 엘리바스·빌닷·소발과 욥의 논쟁 (2:11–13; 4–27)
4. 욥의 항변, 지혜 시, 엘리후 (23–37)
5. 폭풍 속 응답, 창조 세계, 베헤못·리워야단 (38–41)
6. 욥의 응답, 친구들의 책망, 기도와 회복 (42)

## 구현과 사용
- 표지의 설명 애니메이션 버튼에서 6편을 선택해 볼 수 있습니다. 결말까지 포함합니다.
- 이야기 시작 및 다음 장 진입 때 해당 설명이 열립니다. '탐색으로 이어가기'로 즉시 건너뛸 수 있습니다.
- 읽던 장의 설명 다시 보기는 게임 선택과 관찰 상태를 바꾸지 않습니다.
- 실제 Three.js 3D 환경과 관절을 나눈 인물 모델에 몸짓·고개·입 움직임, 카메라 컷과 이동을 적용합니다. MP4나 성우 녹음이 아닙니다.
- 컷별 자막과 전체 대본, 재생·일시정지·탐색 막대·이전/다음 컷·다시 보기 지원.
- 선택적 Web Speech 한국어 기기 읽기: 음색과 지원은 기기별로 다릅니다. 사용자가 켠 경우에만 작동합니다.
- 동작 줄이기에서는 정지 구도와 수동 시작, 자막을 유지합니다. 숨겨진 탭에서는 일시정지합니다.
- 설명이 열리면 기존 탐색 렌더러를 해제하여 이중 렌더링을 피합니다. 로딩 실패 시 대본과 자막으로 볼 수 있습니다.
- 새 파일: src/game/films.ts, filmScene.ts, Cinema.tsx, cinema.css.

## 본문과 연출
대사는 한국어로 새로 요약했으며 직접 인용으로 표시하지 않습니다.
하나님은 빛과 옷자락의 형상, 사탄은 고발자의 형상으로 연출했습니다. 외모·몸짓·공간은 성경의 외모 묘사나 역사적 복원이 아닙니다.
하늘의 대화를 모든 고난의 원인 공식으로 만들지 않습니다. 욥은 그 대화를 듣지 않습니다.
친구와 엘리후의 설명은 등장인물의 주장으로 구분합니다. 아내의 상실, 42:6의 번역 문제, 자녀를 대체로 읽지 않는 관점 등 해석은 대본 주석에 명시합니다.
전문 성서학자의 최종 감수를 받았다는 주장은 하지 않습니다.
